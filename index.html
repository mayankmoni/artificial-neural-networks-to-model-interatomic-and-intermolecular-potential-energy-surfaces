Learning potential energy surfaces with artificial neural networks

Code associated with a simulated-annealing-based ANN approach for representing interatomic and intermolecular potential energy surfaces from structure–energy data.

View Fortran source Read the paper

What this code demonstrates

The publication explores neural-network representations for potential energy surfaces, including a model matrix eigenvalue/eigenvector problem, the OH diatomic potential-energy curve, and the water–formaldehyde dimer intermolecular PES.

The supplied example is a compact, hard-coded network: each 3×3 input matrix is flattened to nine values, mapped through four hidden units, and produces four outputs.

Build and run

Requires a Fortran compiler. This command is a starting point for GNU Fortran; the archival source has not been validated as a turnkey build.

gfortran -std=legacy -ffixed-form \
  -ffixed-line-length-none \
  back-propg4.f -o backprop
./backprop

Inputs are embedded in the source. Inspect the declared output files and compiler behavior before interpreting results.

Source and method notes

The source perturbs one weight at a time and applies an annealing-style acceptance expression. It does not compute analytic gradients in the usual gradient-descent backpropagation workflow. Consult the paper for the method’s intended context.

  • Pattern 4 is commented as “unknown,” but target values are provided and it is included in the training loop.
  • Several legacy implementation details need review before scientific reuse.
  • The included `ran3` routine is attributed to Numerical Recipes; check redistribution terms.
